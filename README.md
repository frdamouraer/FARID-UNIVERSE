# FARID UNIVERSE

Website hub statis, siap diunggah ke GitHub Pages.

## Cara memasang
1. Ekstrak ZIP ini.
2. Upload `index.html`, `style.css`, `script.js`, dan `README.md` ke root repository GitHub.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, pilih branch utama dan folder `/(root)`, lalu simpan.
5. Tunggu GitHub Pages selesai menerbitkan website.

## Kustomisasi
- Teks dan URL: `index.html`
- Warna, Liquid Glass, dan animasi: `style.css`
- Partikel angin: `script.js`

Tidak membutuhkan framework atau proses build. Google Fonts memerlukan koneksi internet.
